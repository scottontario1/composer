Build a chain of skills

Place and snap

Drag a skill from the library. Move a block by its title bar; it settles on the 24-pixel grid. Drop a block just below another to snap their ports together and create a handoff. Snapping moves that block only.

Connect and branch

Click or drag a bottom output port to a top input port. One result can feed multiple steps; a step can combine multiple results. Loops are rejected so the workflow always has a completion order. Select a line to inspect or remove its handoff.

On a phone or tablet

Use Add skill to open the library, then tap a skill to place it. Swipe the canvas background to pan. Tap a block to open settings, or use Edit step. In settings, choose Connect next step and tap Add handoff to connect without dragging ports. Use Done to return to the canvas, or Shared goal to edit the goal directly.

Make each step specific

Select a block to edit its instructions, output path, and workflow options. Edit the shared goal in the side panel or with the Shared goal button. The generated prompt passes the actual upstream artifacts to each dependent step.

Use the keyboard

Focus a block’s title bar and use ↑ ↓ ← → to move one grid cell. Activate ports with Enter to connect them. Escape or Cancel link cancels a connection. Delete removes a selected block or handoff when you are not editing a field.

Save and run

Edits are saved in this browser when storage is available. Export JSON for a portable copy, or get the agent prompt to run the composed workflow. JSON files contain your instructions and output paths. This single file includes a validated catalog and project defaults. Rebuild it after editing skills or orchestration.json. The built date and source fingerprint are shown in the library; an offline page cannot detect later project changes. Export before moving or replacing this file: browser storage may not follow it. If copying or downloading is unavailable, select the visible export text and save it manually. The composer never starts agents or writes skills.
