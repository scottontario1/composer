## Compatible grafts and mandatory final fixes

1. Preserve C's separate icon SVGs, container queries, ownership/lifecycle and quiet Composer page. Graft B's Architect stepped shoulder and How top-right notch as SVG silhouette functions only. Do not import B's viewport-based board layout or bake icons back into stretchable frame art.
2. Replace C's large discrete blooms with finer subdued irregular patina. B's grain/low-frequency patina is a useful idea, but copying its screenshot-strength cloudiness unchanged would keep a material problem. Keep mineral wear subtle and spatially varied; reduce C's thousands of generated wear nodes if equivalent texture can be achieved with fewer shapes or static native filtering.
3. Scope C selected-title rules to the owning panel's direct button/copy. Selecting Architect must not visually underline both children while their aria-pressed is false.
4. Restore the same six descriptive sentences used in Three's selected summary (source catalog/canonical descriptions), including live selection/reset synchronization. This brief-required parity is absent in every native template. Preserve complete safe canonical SKILL.md reader.

Tighten vertical assembly gaps, keep Interrogate's brighter edge, and improve ghost to a faint connector-shaped Swarm with bees/count/drafting guides. The parent must inspect the synthesized version; candidate evidence cannot certify grafts.
6. Confirm exact injected six-document equality, initial Arena visibility, docs following keyboard/API/reset, multiple instances and safe caller text, untouched host siblings on dispose, idempotent disposal, all controls reachable at 390px and a narrow host within a wide viewport. Use requested source/manual browser inspection; no automated tests are implied.

Rejected grafts: A's serif panel titles and heavy yellow rims reduce fidelity; A/B's icons inside anisotropically scaled artwork damage mobile clarity; Three's library/renderer would negate the native architecture constraint; C's current explicit camouflage blooms should not be retained simply to avoid SVG filters.
