## Acceptance inspection

- Domain safety: separate handoffs, causal assertions and contextual references; DAG execution, signed cycle classification, explicit scope.
- Caller fit: Overview plus complete Skills/Loops views; connected investigation example and reusable recipe flow.
- Mobile: complete forms/outlines/cycle paths with optional diagrams; focus, keyboard, 44px targets, safe areas and visible save status.
- Ownership: sole workspace writer; domain rules separated from UI, storage, transfer and compilation; standalone authoring/distribution boundary.
- Compatibility: protected independent legacy migration, old-order seed, layout separation, explicit legacy-export losses, numeric caps and raw recovery.
- Feasibility: five delivery phases and proposed behavior/device/offline verification.
